# Контур

Портативное приложение для Windows с графическим управлением сетевыми стратегиями.
Светлый интерфейс, выбор профиля и один явный запуск вместо набора отдельных BAT-окон.

![Интерфейс Контура](docs/interface.png)

Репозиторий: [FirstRyzen/Zapret-AIUNLOCK-TelegramUnlock](https://github.com/FirstRyzen/Zapret-AIUNLOCK-TelegramUnlock).

## Запуск

1. Скачайте архив релиза и **распакуйте целиком** в доступную для записи папку.
2. Откройте **Kontur.exe** и подтвердите запрос прав администратора.
3. Выберите «Основной» и нажмите «Запустить».
4. Если нужный сайт не открывается, остановите профиль и попробуйте ALT1–ALT13 или другую стратегию.

EXE — портативная оболочка, рядом нужны `bin`, `lists`, `profiles`, `utils` и `licenses`.
Windows x64, .NET Framework 4.8. Дополнительная установка Python, Node или .NET SDK не нужна.
Приложение не подписано цифровой подписью.

## Возможности

- 22 профиля: основной, ALT1–ALT13, EXP, FAKE TLS AUTO и SIMPLE FAKE с вариантами.
- Запуск и остановка собственного winws, вывод ошибок и журнал.
- Игровой фильтр: TCP, UDP, оба протокола; свои порты и диапазоны.
- Редактор добавляемых и исключаемых доменов.
- Сворачивание в трей и запуск выбранного профиля при открытии приложения.
- Отдельные кнопки AI Unlock и Telegram Desktop во вкладке «Инструменты».

«Процесс работает» означает работу движка; доступность сайтов проверяется отдельно.
Настройки применяются при следующем запуске профиля. При выходе Контур останавливает
только запущенный им winws. Другой winws необходимо остановить прежним способом.
Автозапуск при открытии приложения не добавляет программу в автозагрузку Windows.

AI Unlock включает отдельный блок в системном hosts. Отключение удаляет этот блок;
резервные копии находятся в `utils/ai-unlock-backups`. Telegram-прокси — отдельный
процесс с собственным треем: при выходе из Контура он продолжает работать,
остановить его можно кнопкой в «Инструментах». Настройки и секрет Telegram
создаются на компьютере пользователя и не должны попадать в репозиторий.

Настройки оболочки и журналы: `%LOCALAPPDATA%\Kontur`.
Свои домены: `lists/list-general-user.txt` и `lists/list-exclude-user.txt`.

## Сборка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

Сборка использует системный компилятор .NET Framework. `package.ps1` создаёт
`dist/Kontur` и архив `dist/Kontur-1.0.0-win-x64.zip` по явному списку файлов.
В пакет не входят локальные журналы, hosts-бэкапы, секрет Telegram и пользовательские домены.
Исходники оболочки, сборочные скрипты и уведомления об авторах включены.

## Основа и авторы

Контур — самостоятельное название и новый интерфейс **поверх существующего движка**,
а не новый сетевой движок. Используются [zapret / bol-van](https://github.com/bol-van/zapret),
стратегии [Flowseal](https://github.com/Flowseal/zapret-discord-youtube),
[WinDivert](https://github.com/basil00/WinDivert),
[TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy),
адреса [ImMALWARE/dns.malw.link](https://github.com/ImMALWARE/dns.malw.link).
Исходные BAT сохранены в рабочей папке; портативный пакет использует `.args`-профили.
Подробности и лицензии — в `THIRD_PARTY_NOTICES.md` и `licenses`.

## Публикация на GitHub

Публикуйте содержимое **dist/Kontur**, а не всю исходную рабочую папку:
в рабочей папке могут быть личные списки, локальные прокси-настройки и резервные копии hosts.
Архив удобно приложить к GitHub Release. Сетевая работоспособность зависит от провайдера
и выбранного профиля; приложение не обещает доступность каждого сервиса.
