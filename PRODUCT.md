# Контур

<!-- impeccable:product-schema 1 -->

## Platform
Windows desktop, .NET Framework 4.8 / WinForms.

## Purpose and users
Пользователь хочет самостоятельное оформление существующей сборки, EXE-меню, выбор ALT-профиля и настройки; планирует самостоятельно опубликовать на GitHub.

## Confirmed identity
Название «Контур», светлое окно, графитовая навигация, зелёная кнопка запуска — подтверждено пользователем.

## Constraints
Используется существующий winws и стратегии Flowseal/bol-van. Сохраняются исходные BAT и сведения об авторах. Новое меню запускает только свой процесс; изменение hosts и Telegram-прокси не является частью запуска. Нельзя обещать доступность сайтов по факту работы процесса.

## Assumptions
Windows x64. Пользователь подтвердил распространение одним EXE: компоненты встроены и распаковываются автоматически в LocalAppData. Репозиторий FirstRyzen/Zapret-AIUNLOCK-TelegramUnlock.
